🖱️ Detección de clics en el editor

Detecta cuándo haces clic con el ratón dentro del editor de código y te notifica el atajo equivalente al instante.

🎚️ 3 modos de entrenamiento

Suave (avisa), Estricto (bloquea la acción del ratón) y Entrenamiento (además abre el teclado visual).

⌨️ 42 atajos incluidos

Navegación, edición, búsqueda, terminal y Git — los que de verdad se usan a diario.

🚫 Interceptor de 20 comandos

En modo estricto, bloquea 20 comandos nativos que sueles ejecutar con el ratón (abrir settings, terminal, cerrar pestaña...) y te enseña el atajo real.

🎹 Teclado visual QWERTY

Con guía de colores por dedo y posición de reposo, para aprender la digitación correcta.

📊 Estadísticas de progreso

Clics de ratón, atajos mostrados, racha diaria y tu top 5 de atajos más usados.

Cómo funciona

  1. Instala la extensión.
  2. KeyMaster aparece en la barra de estado inferior izquierda.
  3. Actívalo con clic en la barra o con Cmd+Shift+K / Ctrl+Shift+K.
  4. Cada clic con el ratón en el editor muestra una notificación con el atajo que deberías usar.
  5. En modo estricto, además se bloquean 20 comandos nativos que sueles ejecutar con el ratón.
  6. Abre Ctrl+Shift+J / Cmd+Shift+J para practicar en el teclado visual.
¿Bloquea el ratón por completo?

No. Solo en modo Estricto o Entrenamiento bloquea la acción concreta que intentaste hacer con el ratón, y solo para los 20 comandos interceptados.

¿Funciona en Cursor y Windsurf, no solo en VS Code?

Sí. Es compatible con VS Code ≥ 1.85.0, Cursor, Windsurf, Antigravity y VS Codium, en macOS, Windows y Linux.

¿Envía mis estadísticas a algún servidor?

No. Las estadísticas de uso se guardan localmente; KeyMaster no se comunica con ningún servicio externo.

Instalación

Un solo comando si tienes el CLI de VS Code instalado, para macOS, Windows y Linux por igual.

code --install-extension apliarte.keymaster

En Windsurf, Antigravity o Cursor (usan Open VSX, no el Marketplace de Microsoft):

# 1. Descarga el .vsix desde GitHub Releases
# https://github.com/erbolamm/key-master/releases
# 2. Paleta de comandos → "Extensions: Install from VSIX..."
# 3. Selecciona el archivo descargado
